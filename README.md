# Project name : FitLog – Your Personal Workout Companion,

# Description  :
### Track your workouts. Build consistency. Get stronger.

FitLog is a modern, dark-themed fitness companion designed to help users organize their workouts, manage their daily exercise plans, and stay consistent with their fitness journey. Pick a workout, add it to your plan, and keep track of your weekly progress.

## Technologies Used :

- **Next.js** – React framework for building the application.
- **React** – Component-based UI development.
- **TypeScript** – Type safety and improved developer experience.
- **Tailwind CSS** – Responsive and modern styling.
- **React Icons** – Icons for an enhanced user interface.

## Key Features :

1. **Workout Exploration** – Browse available workouts and explore exercise details.

2. **Personalized Workout Plan** – Add workouts to your daily plan and customize your routine.

3. **Workout Management** – Easily remove workouts from your plan with interactive controls.

4. **Responsive Design** – Enjoy a seamless experience across desktop, tablet, and mobile devices.

5. **Modern Dark UI** – A clean, dark-themed interface designed for a focused and enjoyable fitness experience.
